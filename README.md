# Quarter-view\Top-down game planning

## 1. 개임 개요

| 항목 | 내용 |
|---|---|
| 게임 제목 | Blind spot(수정될수있음) |
| 장르 | Top-down / Survival / Escape |
| 개발 엔진 | Unreal Engine 5.4.4 |
| 플랫폼 | PC |
| 플레이 방식 | Single Player |
| 시점 | Quarter-view\Top-down |
| 예상 플레이 시간 | 10분 이상 |

### 한 줄 소개
> 괴물을 피해서 건물을 탈출하는 게임

---

## 2. 게임 컨셉

정체불명의 괴물이 인간을 습격하여, 당신은 건물 옥상으로 피했다. 어느 순간 비명소리가 잠잠해지자 당신은 건물을 내려가기로 결심한다.

놈들은 빛에 극도로 민감하여 낮의 주광을 받으면 광분하여 사방에서 미쳐 날뛰지만, 밤이 되면 극도로 둔해진다. 놈들이 고요해진 지금이 유일한 탈출 기회다.

어둠 속에 잠든 괴물들은 갑작스러운 손전등 불빛을 받으면 시각 신경이 마비되어 순간적으로 굳어버린다. 손전등 하나에 의존해 놈들을 억제하며, 어두운 건물 속을 뚫고 탈출해야 한다.

### 핵심 키워드

- **Explore** : 건물 탐색
- **Collect** : 보안카드 획득
- **Escape** : 건물 탈출

---

## 3. 게임 목표.

1. 건물 내부를 탐색한다.
2. 등장하는 적을 회피한다.
3. 보안카드를 획득한다.
4. 탈출구까지 이동한다.
5. 보안카드를 사용하여 문을 연다.

---

## 4. Core Gameplay Loop
```text
탐색
  ↓
적 발견
  ↓
적 회피 혹은 돌파
  ↓
아이템 획득
  ↓
다음 구역 이동
  ↓
보안카드 획득
  ↓
탈출
```

## 5. 플레이어 조작

| 입력 | 기능 |
|---|---|
| W / A / S / D | 캐릭터 이동 |
| Mouse | 시점 회전 |
| Shift | 달리기 |
| Left Click | 손전등과부화 |
| F | 상호작용 |
---

## 6. 플레이어 기능

### 6.1 이동

플레이어는  Quarter-view\Top-down 방식으로 맵 내부를 이동할수 있다.

주요 기능:

- 앞으로 / 뒤로 이동
- 좌 / 우 이동
- 마우스 시점 회전
- 달리기
- 손전등과부화
